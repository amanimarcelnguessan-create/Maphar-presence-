⚙️ Configuration Firebase requise

Firebase n'est pas encore configuré. Suivez ces 4 étapes pour activer la base de données cloud.

Étape 1 – Créer le projet Firebase Allez sur console.firebase.google.com → "Ajouter un projet" → Nommez-le maphar-presences
Étape 2 – Activer Firestore Dans le projet → "Firestore Database" → "Créer une base de données" → Mode Production → Choisir une région (eur3 recommandé)
Étape 3 – Configurer les règles Firestore Onglet "Règles" → Remplacez par :
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /maphar_reunions/{id} { allow read: if true; allow write: if true; } match /maphar_presences/{id} { allow read, write: if true; } } }
Étape 4 – Coller la configuration dans ce fichier Paramètres du projet → "Vos applications" → Ajouter une app Web → Copier les valeurs dans le bloc firebaseConfig en haut de admin.html et scan.html
Étape 5 – Définir votre URL GitHub Pages Dans le bloc CONFIG de admin.html, remplacez baseUrl par l'URL de votre dépôt GitHub Pages
